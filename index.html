Projects

📄Responsive Landing        Page.

This project features an interactive, fixed-position navigation menu designed for an engaging user experience across all web pages. The menu stays visible as users scroll through the page and dynamically changes its style based on user interactions. By leveraging HTML, CSS, and JavaScript, the menu responds to scrolling and hovering, with smooth transitions in color and style, adding both functionality and aesthetic appeal to the website.

⌚Interactive Stopwatch      Web Application

The Stopwatch Web Application is a fully functional time-tracking tool built using HTML, CSS, and JavaScript. This project is designed to offer a user-friendly experience, allowing users to start, pause, reset, and record lap times with ease. The stopwatch tracks time down to milliseconds, ensuring precision and accuracy, while the lap function enables users to monitor multiple time intervals within a single session.

☁️Weather App.

This project is a web application that fetches real-time weather data from a weather API based on the user's location or a location entered by the user. It provides an intuitive interface that displays current weather conditions, temperature, and other relevant details like humidity, wind speed, and weather descriptions. The app is designed to give users accurate, up-to-date weather information in an easy-to-read format.
